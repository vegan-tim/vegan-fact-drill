# Vegan Fact Drill

A phone-friendly multiple-choice quiz for remembering well-sourced facts about food, climate, animals and health, and where each fact comes from.

**Open the quiz:** https://vegan-tim.github.io/vegan-fact-drill/

## How it works

- Questions come from a private collection of fact cards. Every card cites its sources and errs on the conservative side.
- **Overview** mode asks only the key takeaways. **Detailed** mode asks everything.
- Most questions have a second part asking which organisation and year the figure comes from.
- Progress is saved in your browser on each device.

## Feedback

Spotted a problem? Tap **💬 Feedback** on any question, write a note, then tap **Send as GitHub issue**. Or [open an issue](https://github.com/vegan-tim/vegan-fact-drill/issues/new?labels=quiz-feedback) directly. Notes on wording, answers that look wrong, distractors that are too close, and source problems are all welcome.

## Files

- `index.html`: the whole app, with the questions built in.
- `questions.json`: the same questions as plain data.

These files are generated. Edit the fact cards, not these files.
